# SKYTOPIA Site Safety

Construction site safety CMS — single-file web app (`index.html`), hosted on
GitHub Pages: https://xianwenkoh-creator.github.io/skytopia-safety/

Procore-style UI. Modules: contacts, member & equipment registers, cert-expiry
dashboard, document register, open-actions hub, quality defects (HDB Appendix IV),
per-record printable PDF reports, TBM, inspections, HDB-format site observations
(Appendix VII, before/after photos, rectify→verify→close), checklists, RA/SWP,
training, meetings, incident register, statistics (AFR/LTIFR) and the HDB monthly
safety data report (Appendix VI) with CSV/Excel export.

Data is stored in the browser (localStorage); back up via Settings → Export.
Reports and exports can save straight into the SKYTOPIA Safety folder
(OneDrive `Skytopia\Safety`) via Settings → connect folder (Chrome/Edge).

PTW is handled separately in the SKYTOPIA ePTW app. Daily reports live in the
separate `kkl-dr` repo.
